# 🎮 Família Games

Seu portal nerd definitivo! Página estática com referências sobre jogos, livros de programação e filmes geek.

## 🚀 Como Publicar no GitHub Pages

1. Crie um repositório no GitHub chamado `familia-games` (marque como Public)
2. Faça upload dos arquivos `index.html` e `style.css`
3. Vá em Settings > Pages > Source: branch `main` > Save
4. Acesse: https://seu-usuario.github.io/familia-games/

## 📁 Estrutura

familia-games/
├── index.html
├── style.css
└── README.md
